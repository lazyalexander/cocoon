# an-agent 接入开发预览契约

[English（权威版本）](preview-contract.md) · 简体中文

本文描述开发预览控制面，不是 v0.1 资格。这些操作通过，不能证明隔离、容量或
`SPECIFICATION.md` 里的性能预算已经成立。

Cocoon 不依赖 an-agent。可信适配器把 an-agent 的授权转换成 Cocoon 工作授权。
Cocoon 不解释 spool 规则、silk/kit 标签或业务验收。导出的文件只是候选产物，
不是已验收产物。虚拟机停止也不表示业务任务成功。

## 凭据

状态目录里的管理密钥只授权操作员动作：导入和发布镜像、创建虚拟机、修改保护策略、
分支、回滚、提升候选，以及签发或撤销工作授权。

工作方法必须出示工作授权。管理密钥不能代替它。授权绑定主体、一台虚拟机、该机代际、
动作集合、到期时间和最大导出字节数。动作只有 `inspect`、`guest`、`export` 和
`stop`。一次执行尝试独占一台虚拟机。工作授权不能注册虚拟机、转让、发布镜像、
修改保护策略，也不能作用于另一台虚拟机。

派生授权只能比父授权更窄或相同：动作不多于父授权，到期不更晚，导出上限不更大，
虚拟机和代际相同。父授权撤销后，子授权会被拒绝。令牌只在签发时返回一次，库中只存
SHA-256。日志、guest 环境和命令参数都不写令牌。调用者字符串、任务编号或虚拟机编号
本身不是授权。

## 操作身份

对启动、停止、guest 和导出，`HostRequest.request` 是消费方操作编号。相同编号和
相同参数摘要返回已保存的结果，不会再次执行。相同编号配不同摘要会被拒绝。摘要覆盖
操作内容和授权编号，不覆盖令牌或管理密钥。

如果宿主已经记下意图，但在提交结果前退出，之后的查询结果是 `unknown`。重复同一编号
不会再执行。未知不是成功。超时后用 `operation_status` 查询，不要另起一个编号。
结果未知时，仍然禁止复用磁盘、回滚和删除。

## 控制车道和工作车道

停止、紧急停止、撤销授权和操作查询不会排在 guest 执行、导出、启动或恢复后面。
内存保护由独立定时器运行。连接数、排队请求、读取时间和帧大小都有上限。帧上限仍是
32 KiB。

停止、取消、暂停、恢复和冷恢复是不同操作。guest 退出码、runner 状态和框架停止证据
分开保留。vCPU 数量不是 CPU 时间配额。为 guest 配置的内存也不是宿主总占用。
不支持的能力会被拒绝，不会退回本机执行。

消费方使用 `cocoon-host` 的请求类型。不要读取 SQLite、磁盘布局或 Swift runner 协议。

## 主 agent 上下文

带有 `inspect` 权限的工作授权可对所属 VM 调用 `context`。带版本号的结果包含
当前 VM 状态、活动 attempt 与代际、配置的 CPU/内存和网络状态、允许的工作动作、
导出上限及授权到期时间；不含宿主路径、管理凭据或授权 token。主调用者拥有宿主
请求身份。小 agent 可以在其 VM 内运行并共享 guest 权限，但不会获得独立的宿主
生命周期权限；guest 观测也不能扩大授权。
